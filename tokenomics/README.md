# Tokenomics

{% hint style="warning" %}
The token program on these pages was designed for the v3 deployment. It has not been re-published for the current protocol version, and the pools, contracts, and figures it names are the ones from that period.
{% endhint %}

DER is the governance token of the Derion protocol. The token supply is capped at 100,000 DER and is continuously deflated through a buyback-and-burn mechanism using protocol fees (real yield).

As described in [funding-rate.md](../protocol/funding-rate.md "mention"), a fixed cut of all pool funding (interest and premium) — 1/5 in the current deployment — is collected as the protocol fee when it is flushed. This fee will be autonomously used to buyback-and-burn DER tokens via public DEX(es), effectively distributing the protocol yield to DER holders.

In the first phase of the protocol, due to the limitation of token bridging between networks, each network will have its own sub-token with the exact same tokenomics and incentives (e.g., DER-ARB, DER-BSC, etc.). These tokens will later be merged based on their respective USD values.

Token Distribution:

* Community: 63%
  * Liquidity Mining: 28%
  * Trading Incentive: 21%
  * Referrer Commission: 14%
* Partnership and Growth: 28%
* Core Team: 9%
